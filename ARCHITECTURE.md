# SchedNest Architecture

## Platform Layer

-   Authentication
-   Permissions
-   Notifications
-   Activity
-   Birdy Memory
-   Unified Scheduling Engine
-   Shared Files
-   Integrations

## Product Layer

-   SchedNest Student
-   SchedNest Med
-   SchedNest Teams
-   SchedNest Business
-   SchedNest Life

## Core Rule

Products never duplicate platform functionality.

## Birdy

Birdy consumes shared platform data and produces: - Recommendations -
Conflict detection - Schedule optimization - Cross-product reasoning

## Future

Every future industry edition extends the same platform rather than
creating a separate application.

# Definition of Done

A change is complete when all applicable items are true:

- [ ] Scope is focused.
- [ ] Architecture boundaries are respected.
- [ ] Errors and authorization are handled.
- [ ] Secrets remain server-side.
- [ ] Migrations and policies are reviewed.
- [ ] Foundation verification passes.
- [ ] Lint, type checking, build, and relevant tests pass.
- [ ] Operational failures are visible.
- [ ] Documentation and changelog are updated.
- [ ] Rollback or forward-repair steps exist.

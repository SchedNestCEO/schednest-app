# Engineering

This directory defines how SchedNest is built, reviewed, tested, released, and maintained.

- `STANDARDS.md` — implementation and architecture rules
- `BRANCHING.md` — branch responsibilities
- `RELEASE_PROCESS.md` — release and rollback process
- `TESTING.md` — quality layers and gates
- `DEFINITION_OF_DONE.md` — completion checklist
- `OWNERSHIP.md` — subsystem boundaries

The root `CONSTITUTION.md` remains the highest-level project authority.

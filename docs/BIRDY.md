# Birdy Specification

Birdy is the trusted adaptive coordination intelligence for SchedNest. It is not merely a chatbot.

## Modules

- Memory
- Scheduling
- Optimization
- Prediction
- Recommendations
- Communication
- Learning
- Connectors
- Safety
- Explanations
- Permissions

## Memory Levels

1. Session memory
2. Preference memory
3. Behavioral memory
4. Domain memory
5. Sensitive memory

Users can inspect, edit, delete, pause, and export memory.

## Action Levels

- Observe
- Recommend
- Ask
- Execute
- Never Execute

## Recommendation Contract

Every important recommendation should include reason, confidence, constraints, alternatives, tradeoffs, approval requirement, and undo path.

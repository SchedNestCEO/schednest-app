# ADR-0002: Birdy Uses an Approval-Centered Action Model

- Status: Accepted
- Date: 2026-07-13

## Context
Unrestricted autonomous execution creates authorization, reliability, and accountability risks.

## Decision
Birdy may recommend, explain, prioritize, and draft. Privileged or consequential actions require explicit authorization through controlled services.

## Consequences
The platform preserves human control and auditability, with an additional approval step for some workflows.
